3. Operator di Go

3.1 Operator Aritmatika

Operator Nama Contoh Hasil
+ Penjumlahan 5 + 3 8
- Pengurangan 5 - 3 2
* Perkalian 5 * 3 15
/ Pembagian 10 / 2 5
% Modulus (Sisa Bagi) 10 % 3 1

Contoh Program:

package main import "fmt" func main() { a := 10 b := 3 fmt.Println("a + b =", a + b) // 13 fmt.Println("a - b =", a - b) // 7 fmt.Println("a * b =", a * b) // 30 fmt.Println("a / b =", a / b) // 3 fmt.Println("a % b =", a % b) // 1 }

3.2 Operator Perbandingan

Operator Nama Contoh Hasil
== Sama dengan 5 == 5 true
!= Tidak sama dengan 5 != 3 true
> Lebih besar 5 > 3 true
< Lebih kecil 5 < 3 false
>= Lebih besar atau sama dengan 5 >= 5 true
<= Lebih kecil atau sama dengan 3 <= 5 true

Contoh Program:

package main import "fmt" func main() { nilai := 85 nilaiLulus := 75 fmt.Println("Nilai >= Lulus?", nilai >= nilaiLulus) // true fmt.Println("Nilai == 100?", nilai == 100) // false fmt.Println("Nilai != 0?", nilai != 0) // true }

3.3 Operator Logika

Operator Nama Keterangan
&& AND (dan) true jika SEMUA kondisi true
|| OR (atau) true jika SALAH SATU kondisi true
! NOT (tidak) Membalik nilai boolean

Contoh Program:

package main import "fmt" func main() { umur := 20 punyaKTP := true // AND (&&) bisaNyoblos := umur >= 17 && punyaKTP fmt.Println("Bisa nyoblos?", bisaNyoblos) // OR (||) sudahDewasa := umur >= 17 || umur >= 18 fmt.Println("Sudah dewasa?", sudahDewasa) // NOT (!) belumDewasa := !(umur >= 17) fmt.Println("Belum dewasa?", belumDewasa) }

3.4 Operator Assignment

package main import "fmt" func main() { x := 10 x += 5 // x = x + 5 fmt.Println("x += 5 :", x) // 15 x -= 3 // x = x - 3 fmt.Println("x -= 3 :", x) // 12 x *= 2 // x = x * 2 fmt.Println("x *= 2 :", x) // 24 x /= 4 // x = x / 4 fmt.Println("x /= 4 :", x) // 6 x %= 5 // x = x % 5 fmt.Println("x %= 5 :", x) // 1 }

3.5 Increment dan Decrement

package main import "fmt" func main() { angka := 5 angka++ // angka = angka + 1 fmt.Println("Setelah ++:", angka) // 6 angka-- // angka = angka - 1 fmt.Println("Setelah --:", angka) // 5 }

3.6 Contoh Kasus: Kalkulator Sederhana

package main import "fmt" func main() { var angka1, angka2 float64 var operator string fmt.Print("Masukkan angka pertama: ") fmt.Scan(&angka1) fmt.Print("Masukkan operator (+, -, *, /): ") fmt.Scan(&operator) fmt.Print("Masukkan angka kedua: ") fmt.Scan(&angka2) fmt.Println("\n===== HASIL =====") if operator == "+" { fmt.Println(angka1, "+", angka2, "=", angka1 + angka2) } else if operator == "-" { fmt.Println(angka1, "-", angka2, "=", angka1 - angka2) } else if operator == "*" { fmt.Println(angka1, "*", angka2, "=", angka1 * angka2) } else if operator == "/" { if angka2 != 0 { fmt.Println(angka1, "/", angka2, "=", angka1 / angka2) } else { fmt.Println("Error: Tidak bisa dibagi 0!") } } else { fmt.Println("Operator tidak valid!") } }

Latihan 3

Buatlah program yang menghitung:

  • Luas persegi panjang (panjang × lebar)
  • Keliling persegi panjang (2 × (panjang + lebar))

Input: panjang dan lebar dari user

💡 Tips Operator:

  • Pembagian integer menghasilkan integer: 5 / 2 = 2
  • Untuk hasil desimal, gunakan float: 5.0 / 2.0 = 2.5
  • Operator % hanya untuk integer
  • Go tidak punya operator ** untuk pangkat, gunakan math.Pow()
