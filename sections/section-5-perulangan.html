5. Perulangan (Loop)

5.1 FOR Loop Dasar

Go hanya memiliki satu keyword untuk loop yaitu for, tapi bisa digunakan dengan berbagai cara!

Syntax:

for initialization; condition; post { // kode yang diulang }

Contoh:

package main import "fmt" func main() { // Cetak angka 1-5 for i := 1; i <= 5; i++ { fmt.Println("Angka:", i) } }

5.2 FOR sebagai WHILE

package main import "fmt" func main() { i := 1 // Seperti while di bahasa lain for i <= 5 { fmt.Println("Angka:", i) i++ } }

5.3 Infinite Loop

package main import "fmt" func main() { counter := 0 for { counter++ fmt.Println("Loop ke-", counter) if counter >= 5 { break // Keluar dari loop } } }

5.4 BREAK dan CONTINUE

BREAK - Keluar dari loop:

package main import "fmt" func main() { for i := 1; i <= 10; i++ { if i == 5 { break // Berhenti saat i = 5 } fmt.Println(i) } fmt.Println("Loop selesai") }

CONTINUE - Skip iterasi:

package main import "fmt" func main() { // Cetak angka ganjil 1-10 for i := 1; i <= 10; i++ { if i % 2 == 0 { continue // Skip angka genap } fmt.Println(i) } }

5.5 Nested Loop (Loop Bersarang)

package main import "fmt" func main() { // Membuat pola bintang for i := 1; i <= 5; i++ { for j := 1; j <= i; j++ { fmt.Print("* ") } fmt.Println() } }

Output:

* 
* * 
* * * 
* * * * 
* * * * *

5.6 Loop dengan Range

Digunakan untuk iterasi array, slice, map, atau string:

package main import "fmt" func main() { // Loop dengan array angka := []int{10, 20, 30, 40, 50} for index, nilai := range angka { fmt.Printf("Index %d: %d\n", index, nilai) } // Loop string nama := "Golang" for i, huruf := range nama { fmt.Printf("%d: %c\n", i, huruf) } }

5.7 Contoh: Tabel Perkalian

package main import "fmt" func main() { var angka int fmt.Print("Masukkan angka (1-10): ") fmt.Scan(&angka) fmt.Printf("\n===== TABEL PERKALIAN %d =====\n", angka) for i := 1; i <= 10; i++ { hasil := angka * i fmt.Printf("%d x %d = %d\n", angka, i, hasil) } }

5.8 Contoh: Hitung Faktorial

package main import "fmt" func main() { var n int fmt.Print("Masukkan angka: ") fmt.Scan(&n) faktorial := 1 for i := 1; i <= n; i++ { faktorial *= i } fmt.Printf("Faktorial %d = %d\n", n, faktorial) }

5.9 Contoh: Menu Program

package main import "fmt" func main() { var pilihan int for { fmt.Println("\n===== MENU UTAMA =====") fmt.Println("1. Tambah Data") fmt.Println("2. Lihat Data") fmt.Println("3. Hapus Data") fmt.Println("4. Keluar") fmt.Print("Pilih menu (1-4): ") fmt.Scan(&pilihan) switch pilihan { case 1: fmt.Println("→ Menambah data...") case 2: fmt.Println("→ Menampilkan data...") case 3: fmt.Println("→ Menghapus data...") case 4: fmt.Println("→ Terima kasih!") return // Keluar dari program default: fmt.Println("→ Pilihan tidak valid!") } } }

5.10 Contoh: Deret Fibonacci

package main import "fmt" func main() { var n int fmt.Print("Berapa deret Fibonacci? ") fmt.Scan(&n) a, b := 0, 1 fmt.Print("Deret Fibonacci: ") for i := 1; i <= n; i++ { fmt.Print(a, " ") a, b = b, a+b } fmt.Println() }

💡 Tips Perulangan:

  • Pastikan kondisi loop akan berakhir (hindari infinite loop tidak disengaja)
  • Gunakan break untuk keluar dari loop
  • Gunakan continue untuk skip iterasi tertentu
  • Nested loop bisa membuat program lambat, gunakan seperlunya
  • range lebih praktis untuk iterasi collection
