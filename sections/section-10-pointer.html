10. Pointer dan Method

11.1 Apa Itu Pointer?

Pointer adalah variabel yang menyimpan alamat memori dari variabel lain.

Mengapa Menggunakan Pointer?

  • Mengubah nilai variabel di fungsi lain
  • Efisien untuk data besar (tidak copy)
  • Berbagi data antar fungsi
  • Diperlukan untuk method

11.2 Operator Pointer

  • & - Mengambil alamat memori variabel
  • * - Mengakses nilai dari alamat memori (dereferencing)

11.3 Contoh Dasar Pointer

package main import "fmt" func main() { angka := 10 // & mengambil alamat memori pointer := &angka fmt.Println("Nilai angka :", angka) fmt.Println("Alamat angka :", &angka) fmt.Println("Pointer menyimpan:", pointer) fmt.Println("Nilai dari pointer:", *pointer) // Ubah nilai melalui pointer *pointer = 20 fmt.Println("\nSetelah ubah via pointer:") fmt.Println("Nilai angka:", angka) // ikut berubah! }

11.4 Pointer di Fungsi

Tanpa Pointer (Pass by Value):

package main import "fmt" func ubahAngka(x int) { x = 100 fmt.Println("Di dalam fungsi:", x) } func main() { angka := 10 fmt.Println("Sebelum:", angka) ubahAngka(angka) fmt.Println("Sesudah:", angka) // Tidak berubah! }

Dengan Pointer (Pass by Reference):

package main import "fmt" func ubahAngka(x *int) { *x = 100 fmt.Println("Di dalam fungsi:", *x) } func main() { angka := 10 fmt.Println("Sebelum:", angka) ubahAngka(&angka) fmt.Println("Sesudah:", angka) // Berubah! }

11.5 Pointer dengan Struct

package main import "fmt" type Mahasiswa struct { Nama string IPK float64 } func naikkanIPK(mhs *Mahasiswa, nilai float64) { mhs.IPK += nilai } func main() { mhs := Mahasiswa{ Nama: "Budi", IPK: 3.5, } fmt.Println("IPK sebelum:", mhs.IPK) naikkanIPK(&mhs, 0.2) fmt.Println("IPK sesudah:", mhs.IPK) }

11.6 Apa Itu Method?

Method adalah fungsi yang terikat dengan struct tertentu.

Method memungkinkan kita membuat behavior untuk struct (mirip OOP).

11.7 Deklarasi Method

package main import "fmt" type Persegi struct { Sisi float64 } // Method untuk menghitung luas func (p Persegi) hitungLuas() float64 { return p.Sisi * p.Sisi } // Method untuk menghitung keliling func (p Persegi) hitungKeliling() float64 { return 4 * p.Sisi } func main() { persegi := Persegi{Sisi: 5} fmt.Println("Sisi :", persegi.Sisi) fmt.Println("Luas :", persegi.hitungLuas()) fmt.Println("Keliling:", persegi.hitungKeliling()) }

11.8 Value Receiver vs Pointer Receiver

Value Receiver (tidak mengubah original):

package main import "fmt" type Counter struct { Count int } // Value receiver - tidak mengubah original func (c Counter) increment() { c.Count++ fmt.Println("Di dalam method:", c.Count) } func main() { counter := Counter{Count: 0} fmt.Println("Sebelum:", counter.Count) counter.increment() fmt.Println("Sesudah:", counter.Count) // Tidak berubah! }

Pointer Receiver (mengubah original):

package main import "fmt" type Counter struct { Count int } // Pointer receiver - mengubah original func (c *Counter) increment() { c.Count++ fmt.Println("Di dalam method:", c.Count) } func main() { counter := Counter{Count: 0} fmt.Println("Sebelum:", counter.Count) counter.increment() fmt.Println("Sesudah:", counter.Count) // Berubah! }

11.9 Contoh Praktis: Bank Account

package main import "fmt" type BankAccount struct { Pemilik string Saldo float64 } // Method untuk setor func (b *BankAccount) setor(jumlah float64) { b.Saldo += jumlah fmt.Printf("✓ Setor Rp %.2f berhasil\n", jumlah) } // Method untuk tarik func (b *BankAccount) tarik(jumlah float64) bool { if b.Saldo >= jumlah { b.Saldo -= jumlah fmt.Printf("✓ Tarik Rp %.2f berhasil\n", jumlah) return true } fmt.Println("✗ Saldo tidak cukup!") return false } // Method untuk cek saldo func (b BankAccount) cekSaldo() { fmt.Printf("Saldo %s: Rp %.2f\n", b.Pemilik, b.Saldo) } func main() { rekening := BankAccount{ Pemilik: "Budi Santoso", Saldo: 1000000, } fmt.Println("===== BANK ACCOUNT =====") rekening.cekSaldo() rekening.setor(500000) rekening.cekSaldo() rekening.tarik(300000) rekening.cekSaldo() rekening.tarik(2000000) // Gagal rekening.cekSaldo() }

11.10 Contoh: Product dengan Method

package main import "fmt" type Product struct { Name string Price float64 Stock int } func (p *Product) jual(jumlah int) bool { if p.Stock >= jumlah { p.Stock -= jumlah total := float64(jumlah) * p.Price fmt.Printf("✓ Terjual %d %s - Total: Rp %.2f\n", jumlah, p.Name, total) return true } fmt.Println("✗ Stok tidak cukup!") return false } func (p *Product) tambahStok(jumlah int) { p.Stock += jumlah fmt.Printf("✓ Stok %s bertambah %d unit\n", p.Name, jumlah) } func (p Product) info() { fmt.Printf("%s - Rp %.2f (Stok: %d)\n", p.Name, p.Price, p.Stock) } func main() { laptop := Product{ Name: "Laptop Gaming", Price: 15000000, Stock: 5, } fmt.Println("===== INFO PRODUK =====") laptop.info() fmt.Println("\n===== TRANSAKSI =====") laptop.jual(2) laptop.info() laptop.tambahStok(10) laptop.info() }

11.11 Method dengan Multiple Struct

package main import "fmt" import "math" type Lingkaran struct { Radius float64 } func (l Lingkaran) luas() float64 { return math.Pi * l.Radius * l.Radius } func (l Lingkaran) keliling() float64 { return 2 * math.Pi * l.Radius } type PersegiPanjang struct { Panjang float64 Lebar float64 } func (p PersegiPanjang) luas() float64 { return p.Panjang * p.Lebar } func (p PersegiPanjang) keliling() float64 { return 2 * (p.Panjang + p.Lebar) } func main() { lingkaran := Lingkaran{Radius: 7} persegi := PersegiPanjang{Panjang: 10, Lebar: 5} fmt.Println("===== LINGKARAN =====") fmt.Printf("Radius : %.2f\n", lingkaran.Radius) fmt.Printf("Luas : %.2f\n", lingkaran.luas()) fmt.Printf("Keliling: %.2f\n", lingkaran.keliling()) fmt.Println("\n===== PERSEGI PANJANG =====") fmt.Printf("Panjang : %.2f\n", persegi.Panjang) fmt.Printf("Lebar : %.2f\n", persegi.Lebar) fmt.Printf("Luas : %.2f\n", persegi.luas()) fmt.Printf("Keliling: %.2f\n", persegi.keliling()) }

💡 Kapan Menggunakan Pointer Receiver?

Gunakan pointer receiver ketika:

  • ✓ Method perlu mengubah nilai struct
  • ✓ Struct berukuran besar (efisiensi)
  • ✓ Ingin konsisten dengan method lain yang pakai pointer

Gunakan value receiver ketika:

  • ✓ Method hanya membaca data
  • ✓ Struct kecil dan simple
  • ✓ Ingin immutable behavior
