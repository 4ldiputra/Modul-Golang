1. Pengenalan Go (Golang)

1.1 Apa Itu Go?

Go (atau Golang) adalah bahasa pemrograman open source yang dikembangkan oleh Google pada tahun 2007 dan dirilis ke publik pada tahun 2009.

Pencipta Go:

  • Robert Griesemer
  • Rob Pike
  • Ken Thompson

1.2 Mengapa Belajar Go?

Keunggulan Go:

  • ✅ Sederhana dan Mudah Dipelajari - Syntax yang bersih dan minimal
  • ✅ Cepat dan Efisien - Performa mendekati C/C++
  • ✅ Concurrent Programming - Goroutines untuk multitasking
  • ✅ Strongly Typed - Type safety yang ketat
  • ✅ Garbage Collection - Memory management otomatis
  • ✅ Cross Platform - Kompilasi ke berbagai OS
  • ✅ Standard Library Lengkap - Built-in tools yang powerful

1.3 Program Go Pertama

Hello World dalam Go

package main import "fmt" func main() { fmt.Println("Hello, World!") }

Penjelasan Kode:

  • package main - Setiap program Go harus memiliki package main
  • import "fmt" - Import package fmt untuk formatting I/O
  • func main() - Fungsi utama, entry point program
  • fmt.Println() - Fungsi untuk print dengan newline

1.4 Struktur Program Go

// 1. Package declaration (wajib) package main // 2. Import statements import ( "fmt" "math" ) // 3. Konstanta const PI = 3.14 // 4. Variabel global var nama string = "Budi" // 5. Fungsi main (entry point) func main() { fmt.Println("Program dimulai") hitungLuas() } // 6. Fungsi lainnya func hitungLuas() { var r float64 = 7 luas := PI * r * r fmt.Println("Luas lingkaran:", luas) }

1.5 Cara Menjalankan Program Go

Metode 1: go run (langsung jalankan)

go run main.go

Metode 2: go build (compile dulu)

go build main.go ./main

1.6 Input dan Output Dasar

Contoh Program Input-Output

package main import "fmt" func main() { var nama string var umur int // Input fmt.Print("Masukkan nama: ") fmt.Scan(&nama) fmt.Print("Masukkan umur: ") fmt.Scan(&umur) // Output fmt.Println("===== DATA DIRI =====") fmt.Println("Nama:", nama) fmt.Println("Umur:", umur, "tahun") }
