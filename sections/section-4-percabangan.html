4. Percabangan (Conditional)

4.1 IF Statement

IF digunakan untuk menjalankan kode jika kondisi tertentu terpenuhi (true).

Syntax Dasar:

if kondisi { // kode yang dijalankan jika kondisi true }

Contoh Program:

package main import "fmt" func main() { nilai := 85 if nilai >= 75 { fmt.Println("Selamat! Anda LULUS") } }

4.2 IF-ELSE Statement

package main import "fmt" func main() { nilai := 65 if nilai >= 75 { fmt.Println("LULUS") } else { fmt.Println("TIDAK LULUS") } }

4.3 IF-ELSE IF-ELSE

package main import "fmt" func main() { nilai := 85 if nilai >= 90 { fmt.Println("Grade: A") } else if nilai >= 80 { fmt.Println("Grade: B") } else if nilai >= 70 { fmt.Println("Grade: C") } else if nilai >= 60 { fmt.Println("Grade: D") } else { fmt.Println("Grade: E") } }

4.4 Nested IF (IF Bersarang)

package main import "fmt" func main() { nilai := 85 kehadiran := 80 if nilai >= 75 { if kehadiran >= 75 { fmt.Println("LULUS dengan kehadiran baik") } else { fmt.Println("LULUS tapi kehadiran kurang") } } else { fmt.Println("TIDAK LULUS") } }

4.5 IF dengan Short Statement

Go memungkinkan deklarasi variabel langsung di dalam IF:

package main import "fmt" func main() { // Deklarasi dan cek dalam satu baris if nilai := 85; nilai >= 75 { fmt.Println("Nilai:", nilai, "- LULUS") } else { fmt.Println("Nilai:", nilai, "- TIDAK LULUS") } // nilai tidak bisa diakses di luar if // fmt.Println(nilai) // ERROR! }

4.6 SWITCH Statement

SWITCH adalah alternatif dari multiple IF-ELSE, lebih rapi dan mudah dibaca.

Contoh Switch Dasar:

package main import "fmt" func main() { hari := 3 switch hari { case 1: fmt.Println("Senin") case 2: fmt.Println("Selasa") case 3: fmt.Println("Rabu") case 4: fmt.Println("Kamis") case 5: fmt.Println("Jumat") case 6: fmt.Println("Sabtu") case 7: fmt.Println("Minggu") default: fmt.Println("Hari tidak valid") } }

4.7 Switch dengan Multiple Case

package main import "fmt" func main() { hari := "Sabtu" switch hari { case "Senin", "Selasa", "Rabu", "Kamis", "Jumat": fmt.Println("Hari kerja") case "Sabtu", "Minggu": fmt.Println("Hari libur") default: fmt.Println("Hari tidak valid") } }

4.8 Switch dengan Kondisi

package main import "fmt" func main() { nilai := 85 switch { case nilai >= 90: fmt.Println("Grade: A") case nilai >= 80: fmt.Println("Grade: B") case nilai >= 70: fmt.Println("Grade: C") case nilai >= 60: fmt.Println("Grade: D") default: fmt.Println("Grade: E") } }

4.9 Contoh Kasus Lengkap: Sistem Penilaian

package main import "fmt" func main() { var nama string var nilaiTugas, nilaiUTS, nilaiUAS float64 fmt.Print("Masukkan nama: ") fmt.Scan(&nama) fmt.Print("Nilai Tugas (0-100): ") fmt.Scan(&nilaiTugas) fmt.Print("Nilai UTS (0-100): ") fmt.Scan(&nilaiUTS) fmt.Print("Nilai UAS (0-100): ") fmt.Scan(&nilaiUAS) // Hitung nilai akhir (Tugas 30%, UTS 30%, UAS 40%) nilaiAkhir := (nilaiTugas * 0.3) + (nilaiUTS * 0.3) + (nilaiUAS * 0.4) fmt.Println("\n===== HASIL PENILAIAN =====") fmt.Println("Nama :", nama) fmt.Println("Nilai Tugas :", nilaiTugas) fmt.Println("Nilai UTS :", nilaiUTS) fmt.Println("Nilai UAS :", nilaiUAS) fmt.Printf("Nilai Akhir : %.2f\n", nilaiAkhir) // Tentukan grade var grade string switch { case nilaiAkhir >= 90: grade = "A" case nilaiAkhir >= 80: grade = "B" case nilaiAkhir >= 70: grade = "C" case nilaiAkhir >= 60: grade = "D" default: grade = "E" } fmt.Println("Grade :", grade) // Tentukan kelulusan if nilaiAkhir >= 70 { fmt.Println("Status : LULUS ✓") } else { fmt.Println("Status : TIDAK LULUS ✗") } }

Latihan 4

Buatlah program kalkulator BMI (Body Mass Index):

  • Input: berat (kg) dan tinggi (meter)
  • Rumus: BMI = berat / (tinggi * tinggi)
  • Kategori:
    • BMI < 18.5: Kurus
    • 18.5 - 24.9: Normal
    • 25 - 29.9: Gemuk
    • ≥ 30: Obesitas

💡 Tips Percabangan:

  • Gunakan switch jika ada banyak kondisi yang membandingkan nilai yang sama
  • Gunakan if-else untuk kondisi yang lebih kompleks
  • Di Go, tidak perlu break di switch (otomatis break)
  • Gunakan fallthrough jika ingin lanjut ke case berikutnya
