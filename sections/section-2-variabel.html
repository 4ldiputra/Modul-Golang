2. Variabel dan Tipe Data

2.1 Apa Itu Variabel?

Variabel adalah tempat untuk menyimpan data di memori komputer. Setiap variabel memiliki:

  • Nama - Identifier untuk mengakses data
  • Tipe Data - Jenis data yang disimpan
  • Nilai - Data yang tersimpan

2.2 Cara Deklarasi Variabel

Metode 1: Menggunakan var

package main import "fmt" func main() { // Deklarasi dengan tipe data var nama string = "Budi" var umur int = 25 var tinggi float64 = 170.5 fmt.Println("Nama :", nama) fmt.Println("Umur :", umur) fmt.Println("Tinggi:", tinggi, "cm") }

Metode 2: Type Inference

package main import "fmt" func main() { // Go otomatis mendeteksi tipe data var nama = "Ani" // string var umur = 23 // int var tinggi = 165.0 // float64 fmt.Println(nama, umur, tinggi) }

Metode 3: Short Declaration (:=)

package main import "fmt" func main() { // Cara paling singkat dan sering dipakai nama := "Citra" umur := 22 sudahMenikah := false fmt.Println(nama, umur, sudahMenikah) }

2.3 Tipe Data Dasar di Go

Kategori Tipe Data Keterangan Contoh
Integer int8 -128 hingga 127 var x int8 = 100
int16 -32768 hingga 32767 var x int16 = 30000
int32 -2 miliar hingga 2 miliar var x int32 = 1000000
int64 Sangat besar var x int64 = 999999999
Float float32 Desimal 32-bit var x float32 = 3.14
float64 Desimal 64-bit (lebih akurat) var x float64 = 3.14159265359
String string Teks var nama string = "Golang"
Boolean bool true atau false var aktif bool = true

2.4 Contoh Program Lengkap

package main import "fmt" func main() { // Data mahasiswa nim := "2024001" nama := "Siti Nurhaliza" umur := 20 ipk := 3.85 aktif := true // Tampilkan data fmt.Println("===== DATA MAHASISWA =====") fmt.Println("NIM :", nim) fmt.Println("Nama :", nama) fmt.Println("Umur :", umur, "tahun") fmt.Println("IPK :", ipk) fmt.Println("Status:", aktif) }

2.5 Multiple Variable Declaration

package main import "fmt" func main() { // Deklarasi banyak variabel sekaligus var ( nama = "Budi" umur = 25 kota = "Jakarta" menikah = false ) // Atau dengan short declaration x, y, z := 10, 20, 30 fmt.Println(nama, umur, kota, menikah) fmt.Println(x, y, z) }

2.6 Konstanta

package main import "fmt" func main() { // Konstanta tidak bisa diubah const PI = 3.14159 const NAMA_APLIKASI = "Sistem Perpustakaan" const VERSI = 1.0 fmt.Println("Aplikasi:", NAMA_APLIKASI) fmt.Println("Versi :", VERSI) fmt.Println("Nilai PI:", PI) // PI = 3.14 // ERROR! Tidak bisa ubah konstanta }

Kemudian tampilkan semua data tersebut!

💡 Tips Penting:

  • Gunakan := untuk deklarasi singkat di dalam fungsi
  • Gunakan var untuk variabel global atau eksplisit tipe
  • Nama variabel harus dimulai dengan huruf atau underscore
  • Go bersifat case-sensitive: nama ≠ Nama
  • Variabel yang tidak dipakai akan error saat compile
